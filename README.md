# Ogl-Project1
Bu proje windows 11 üzerinde visual studio 2022 comminty edition kullanılarak oluşturulmuştur. 
"\Sorgu\Proje\Project1\Project1.sln" yolundaki visual studio solution ile açılabilir. 
Kendi bilgisayarımdan başka bilgisayarda deneme şansım olmadığı için proje ile gelmeyen herhangi bir gereksinimi var mı bilmiyorum. (driver vb.)
Tüm kaynak dosyaları "\Sorgu\Proje\Project1\Project1" dosya yolunda bulunabilir.
Harici dll'ler "\Sorgu\Proje\DLL" dosya yolundadır.
Tüm harici kütüphaneler "\Sorgu\Include" dosya yolunda bulunabilir.
Umarım beğenirsiniz iyi keşifler!
